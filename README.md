# Advanced Portfolio Website

## Features
- Modern Dark Neon UI
- Responsive Design
- Scroll Animations
- Typing Animation
- Glassmorphism
- GitHub Pages Ready

## How to Edit
Open:
- index.html
- style.css
- script.js

Change:
- Your name
- Projects
- Links
- Images
- Skills
- Contact Info

## Deploy to GitHub Pages

1. Upload all files to GitHub
2. Open repository Settings
3. Go to Pages
4. Deploy from branch
5. Select main branch

Done.
